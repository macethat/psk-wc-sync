GA4 Ecommerce Manual - DataLayer Pushes

Fecha: 24 Jul 2026

Archivo: wp-content/themes/nutritix-child/functions.php (líneas 1434-1548)

Problema

GTM Kit (gratuito) no genera los eventos estándar de WooCommerce en el dataLayer. La integración WooCommerce de GTM Kit requiere el addon premium. Como resultado, GA4 no recibía view_item, add_to_cart, begin_checkout ni purchase.

Solución

Se agregaron dataLayer pushes manuales para los 4 eventos faltantes. Cada evento sigue el schema GA4 con ecommerce: { currency, value, items[] }.

Eventos agregados

1. view_item

Hook: wp_footer con is_product()

Razón: El hook estándar woocommerce_after_single_product no se ejecuta con Elementor. Se usa wp_footer con el conditional tag de WooCommerce.

{
  event: 'view_item',
  ecommerce: {
    currency: 'USD',
    value: 29.99,
    items: [{
      item_id: 'SKU-O-ID',
      item_name: 'Nombre Producto',
      price: 29.99,
      quantity: 1
    }]
  }
}

2. add_to_cart

Hook: woocommerce_add_to_cart (priority 5, accepts 6 args)

Nota: Soporta productos variables — usa variation_id si existe.

{
  event: 'add_to_cart',
  ecommerce: {
    currency: 'USD',
    value: 59.98,
    items: [{
      item_id: 'SKU-O-ID',
      item_name: 'Nombre Producto',
      price: 29.99,
      quantity: 2
    }]
  }
}

3. begin_checkout

Hook: woocommerce_before_checkout_form

Nota: Toma todos los items del carrito activo (WC()->cart).

{
  event: 'begin_checkout',
  ecommerce: {
    currency: 'USD',
    value: 89.97,
    items: [
      { item_id: 'SKU-1', item_name: 'Prod 1', price: 29.99, quantity: 2 },
      { item_id: 'SKU-2', item_name: 'Prod 2', price: 29.99, quantity: 1 }
    ]
  }
}

4. purchase

Hook: woocommerce_thankyou

Nota: Incluye transaction_id con el número de orden.

{
  event: 'purchase',
  ecommerce: {
    transaction_id: '1234',
    value: 89.97,
    currency: 'USD',
    items: [
      { item_id: 'SKU-1', item_name: 'Prod 1', price: 29.99, quantity: 2 },
      { item_id: 'SKU-2', item_name: 'Prod 2', price: 29.99, quantity: 1 }
    ]
  }
}

El script busca pushes de dataLayer.push con contenido ecommerce en la página de producto.

Notas

  • Cada push va precedido de dataLayer.push({ ecommerce: null }) para limpiar el estado anterior (requisito GA4).
  • El SKU se usa como item_id si existe; si no, se usa el ID numérico del producto.
  • Los eventos existentes de GTM Kit (remove_from_cart, add_shipping_info, add_payment_info) se mantienen.
